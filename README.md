# Thực Hành Xử Lý Ảnh và Thị Giác Máy Tính (OpenCV)

Chào mừng bạn đến với kho lưu trữ các bài tập thực hành môn Xử Lý Ảnh. 
Repo này lưu lại toàn bộ quá trình mình học thư viện `OpenCV` bằng Python, với các dòng code được comment cực kỳ dễ hiểu.

## 🛠️ Các thư viện sử dụng
- Python 3.x
- OpenCV (`pip install opencv-python`)
- Numpy (`pip install numpy`)

## 📚 Nội dung thực hành
- [x] Đọc, hiển thị và lưu ảnh.
- [x] Thay đổi kích thước (Resize), cắt ảnh (Crop).
- [x] Chuyển đổi không gian màu (Ảnh xám, Ảnh nhị phân).
- [x] Vẽ hình học và chèn chữ lên ảnh.
- [ ] Lọc nhiễu, làm mờ ảnh.
- [ ] Nhận diện đường viền (Canny Edge Detection).
